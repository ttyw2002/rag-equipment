# 장비 오류 이력 시맨틱 검색

반도체 공정 장비의 오류 이력을 **의미로 검색**하는 웹 앱입니다.
검색어가 이력에 그대로 적혀 있지 않아도 관련된 내용을 찾아냅니다.

🔗 **[앱 열어보기](https://rag-equipment-kph5udr3ejox5vsa8c32qh.streamlit.app/)**

---

## 만든 이유

장비에 문제가 생기면 과거에 같은 일이 있었는지부터 찾습니다.
그런데 이력 조회는 엑셀 필터나 Ctrl+F에 의존합니다. 
하지만 여기에는 같은 현상을 사람마다 다르게 적는 문제가 있습니다.

| 담당자 A | 담당자 B | 담당자 C |
|---|---|---|
| 챔버 압력 이상 | 진공도 저하 | Base pressure 미도달 |

"압력"으로 검색하면 B와 C가 적은 이력은 나오지 않습니다.

**더 큰 문제는 증상과 원인이 다른 경우입니다.**

`기판 냉각 불량으로 온도 상승` — 온도 문제로 보이지만,
실제 원인은 `Backside He 공급 압력 부족`이었습니다.

압력 문제를 조사하는 사람은 이 이력을 단순 검색 만으로는 찾을 수 없습니다.
카테고리가 '온도'로 분류되어 있으니까요.

---

## 동작하는 방식

글자를 맞춰보는 대신, **문장의 의미를 숫자로 바꿔서 비교**합니다.

문장을 숫자 목록(벡터)으로 변환하면 비슷한 뜻일수록 가까운 위치에 놓입니다.
`강아지`와 `개`는 가깝고, `강아지`와 `파인애플`은 멉니다.
글자가 하나도 안 겹쳐도 의미가 통하면 가까워집니다.

이력 전체를 이렇게 변환해두고, 질문도 같은 방식으로 변환해
**가장 가까운 이력**을 찾아옵니다.

### 실제 검색 결과

"압력 관련 오류 이력"으로 검색했을 때 나온 것들입니다.

| 검색된 이력 | '압력'이라는 단어 |
|---|---|
| Base pressure 5E-3 Torr 미도달 | 없음 (영어로 적힘) |
| 기판 냉각 불량으로 온도 상승 | 없음 (원인이 압력) |
| 플라즈마 점화 실패 반복 | 없음 (RF 문제로 분류됨) |

세 건 모두 엑셀 필터로는 찾을 수 없는 이력입니다.

---

## 처리 과정

[준비 - 최초 1회]
엑셀 이력 → 문장으로 재구성 → 숫자 벡터로 변환 → 저장

[검색 - 질문할 때마다]
질문 → 벡터로 변환 → 가까운 이력 5건 찾기 → AI가 읽고 정리 → 답변


앞부분(검색)이 **Retrieval**, 뒷부분(정리)이 **Generation**입니다.
둘을 합쳐 RAG(Retrieval-Augmented Generation)라고 부릅니다.

AI가 아는 지식으로 답하는 게 아니라,
**찾아온 이력만 읽고 답하게** 만드는 것이 핵심입니다.
그래야 없는 내용을 지어내지 않습니다.

## 만들면서 판단한 것들

### 한 줄짜리 이력에 맥락을 붙임

이력 한 건은 짧은 문장입니다. 그대로 변환하면 벡터가 뭉뚱그려져
서로 구별이 안 됩니다.

그래서 흩어진 항목을 하나의 문장으로 엮었습니다.

장비: PECVD-03 (PECVD) | 공정: SiO2 증착
증상: 챔버 진공도 미달
원인: O-ring 열화에 의한 미세 leak
조치: O-ring 교체 후 leak check 재실시

증상뿐 아니라 원인과 조치까지 넣은 덕분에,
앞서 말한 '온도 증상 + 압력 원인' 이력도 검색됩니다.

### AI 요약과 원본을 분리

AI가 정리해준 답만 보여주면 근거를 확인할 방법이 없습니다.
엔지니어가 판단해야 하는 일에서는 위험합니다.

- **AI 요약 탭** — 여러 이력을 묶어 정리
- **원본 탭** — 검색된 이력 그대로

답변에는 이력 번호를 반드시 인용하게 했습니다.

### 검색용과 필터용을 나눔

장비종류나 다운타임 같은 항목은 의미 검색 대상이 아니라
**조건으로 걸러낼 값**입니다. 본문과 분리해 저장하고
"PECVD 장비만" 같은 필터에 사용했습니다.

## 아직 안 되는 것

**에러코드로는 잘 못 찾습니다.**
`E-1021` 같은 코드는 의미가 없는 문자열이라 의미 검색이 약합니다.
키워드 검색을 함께 쓰는 방식으로 보완할 계획입니다.

**공정 지식은 모릅니다.**
엔지니어는 유량과 압력이 물리적으로 얽혀 있다는 걸 알지만,
범용 AI 모델은 모릅니다. 이 간극을 메우는 것이 다음 과제입니다.

**짧은 단어보다 문장이 잘 됩니다.**
`열화` 두 글자보다 `부품이 노후화되어 발생한 문제`처럼
문장으로 물어야 정확합니다.
